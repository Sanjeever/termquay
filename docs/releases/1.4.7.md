- Add explicit Chinese font fallbacks to every terminal font preset while retaining Latin monospace fonts.
- Align WebGL glyphs to physical pixels at fractional display scaling, preventing row-dependent Chinese text blur.
- Accept the expanded local terminal shortcut set when importing portable settings.
- Update English and Chinese workflow guidance. Verification evidence and remaining native/service gaps are recorded in the [verification ledger](https://github.com/Sanjeever/termquay/blob/main/docs/development.md#release-147-verification-2026-11-12).
