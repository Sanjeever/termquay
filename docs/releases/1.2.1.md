## 连接与终端

- 新增可搜索的远端服务快捷入口。
- tmux 会话支持新建绑定标签并附着，断线或恢复布局后可显式继续附着。
- 启用 Shell 集成后，终端与工作区标签展示命令运行、后台完成和失败状态，可为当前命令开启一次性完成提醒。
- 修复 Bash 集成的提示符钩子拼接与 Readline 键位错误，避免已有提示符命令以分号结尾时持续报错。
- 自动重连核对原会话的完整跳板路径，路径配置改变后转为手动处理。

## 多主机任务与巡检

- 多主机任务支持收起到后台，从底部任务入口查看进度、处理首台确认和返回执行结果。
- 完成的执行记录可显式加密保存、移除，或载入定义创建新任务；任务不能跨应用重启续跑。
- 新增退出码、文本、正则和 JSON 字段巡检条件，以及跨主机文件基线比较，提供主机与步骤总览及判定原因。
- 基线变化、输出截断或解析失败时明确显示无法判定；取消任务不保证远端派生进程终止。

## 文件操作

- 支持在同一或不同 SSH 工作区间复制粘贴远端普通文件，以及将系统剪贴板中的本地文件粘贴上传。
- 传输前确认来源、目标与文件，同名默认跳过；执行时复核来源连接和文件版本。
- 点击目录同步等动作后自动收起文件视图菜单，排序和开关选项保持菜单打开。

## 界面修复

- 修复终端长菜单超出窗口的问题，支持菜单内部滚动和键盘定位底部项目。
- 关闭菜单、选择框和选项弹层动画，避免透明度动画交接时面板短暂消失。
- 修复通用样式限制大对话框宽度的问题，调整进程、服务和端口列表布局，增强操作入口的辨识度。
- 修复下拉框及选项文字显示不完整的问题。

## 构建修复

- 补齐 Windows 系统通知依赖、校验记录与许可材料，修复三平台发布流程失败。

## 验证范围

- 发布准备已通过 macOS 本地 Go 测试与前端逻辑测试。新增能力的真实远端链路、跨平台原生交互与升级链路仍需在目标环境确认。
