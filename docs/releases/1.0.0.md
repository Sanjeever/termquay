## 首个正式版本

- 统一管理 SSH、RDP 和本地终端，支持连接分组、搜索、收藏、最近记录，以及 OpenSSH / PuTTY 配置预览导入。
- SSH 支持密码、私钥、Agent、用户证书、交互认证、跳板链、SOCKS5 代理和端口转发。
- 多工作区、终端与双窗格，支持查找、命令片段、多主机执行、tmux 入口和终端输出记录。
- 远端文件树与多编码编辑，支持保存冲突对比、批量传输、显式续传、目录同步和大日志分片查看。
- 按需 Linux 监控，展示 CPU、内存、网络、磁盘趋势与文件系统容量。
- 内嵌 RDP，支持经 SSH 访问内网桌面；Windows 另提供系统 RDP 客户端入口。
- 本地凭据加密保存，提供加密文件与 WebDAV 快照、预览恢复，以及可选本地草稿与工作布局恢复。
- 提供版本检查、更新日志和用户确认后的下载与重启更新。

## 安装与更新

- Windows 需要 WebView2；macOS 压缩包包含完整应用；Linux 需要 GTK4 和 WebKitGTK 6.0 运行库。
- 将程序解压至当前用户可写目录后运行。原位更新需要程序所在目录可写，重启会断开活动连接并停止传输；未保存文件和本地状态先经过退出确认。
- 开发构建不自动检查或安装更新。正式构建可在“设置 → 关于”关闭自动检查。

## 已知限制

- 内嵌 RDP 当前使用 TLS 1.2，无法连接仅允许 TLS 1.3 的目标。操作系统截获的快捷键仍受系统限制。
- SSH 和 RDP 活动会话不能跨重启恢复；布局恢复保持断开，不自动执行命令或上传草稿。
- 远端文件保存不保留全部 ACL 和扩展属性，外部写入者与保存之间仍存在竞争窗口。
- 各平台原生验收范围、真实 WebDAV 和持续负载验证缺口见仓库开发说明。签名与公证状态以对应构建记录为准。
