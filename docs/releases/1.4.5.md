## SSH 工作区与文件

- 新增固定右侧工具栏，提供文件、监控、AI、转发、传输、片段与 Docker 入口，支持键盘导航。
- 远端文件面板可跟随活动终端上报的目录。Bash/Zsh 目录上报支持显式设置、脚本预览与插入，不自动执行。
- 可将选中远端文件或当前目录带入文件传输工具，保留左侧位置。复制仍需显式预览和执行。
- Shell 集成采用一次可展开预览，将目录上报与命令记录、增强补全钩子分开。

## 终端与 Docker 修复

- 选中、快捷键、菜单和浏览器复制统一移除终端每行末尾的 ASCII 空格，保留缩进与内部空格。
- 降低深色 TUI 面板背景亮度，保留 xterm 文字对比度调整。
- 改善连接状态与窄栏监控指标的可读性。
- 可用 SSH 目标列表更新时保留 Docker 容器视图、日志与终端状态。
