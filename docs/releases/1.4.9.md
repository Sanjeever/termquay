## SSH workspaces

- Arrange SSH tabs in three or four panes without restarting terminals or losing editor drafts. Compact mode adds split buttons and opens monitoring in new wide workspaces.
- Draft commands and snippets per terminal. **Insert into terminal** waits for a separate Enter at the shell prompt. Multiline drafts require active bracketed paste and are retained when insertion is blocked.
- Switch the file panel between the directory tree and a sortable list. Manual navigation pauses terminal directory following.
- See current network and disk rates and root filesystem usage in the monitoring overview.

## Connection catalog and guides

- Open or locate a workspace from a compact connection row and choose visible columns from the header.
- Consolidate layout, directory reading, resource generation and release guidance. Check affected documentation and examples alongside interface and behavior changes.

## SSH 工作区

- 支持三窗格和四窗格，调整布局时保留终端和编辑草稿。紧凑模式提供分屏按钮，新建宽窗口工作区时显示监控。
- 在各终端分别编辑命令草稿和片段。「插入终端」后仍需在 Shell 提示符处按 Enter。多行草稿需要启用括号粘贴，无法安全插入时保留草稿。
- 文件面板可在目录树和可排序的目录列表之间切换。手动导航会暂停跟随终端目录。
- 监控概览显示当前网络与磁盘速率，以及根文件系统使用量。

## 连接目录与文档
