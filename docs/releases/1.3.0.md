## 本机 CLI

- 同一程序无参数启动桌面，支持独立帮助和本机版本查询。
- 新增实例状态、保存连接筛选和 SSH 工作区查询；连接信息显式排除凭据与内部认证配置。
- 可通过精确工作区 ID，在已有 SSH 连接上执行独立、无 PTY 的 `sh -s` 命令。支持正文、文件和 stdin 输入、整秒超时、JSON 输出与非交互调用。
- 结果包含标准流、远端退出码、耗时、截断与结构化错误。取消或传输中断时明确表达远端状态未知，不自动重放。

## 本机授权与运行前提

- “设置 → 本机 CLI”新增默认关闭的访问开关，授权同一系统用户的本机进程；本机授权不随备份迁移。
- Windows 使用当前用户命名管道，macOS/Linux 使用受保护 Unix socket，不监听网络端口。
- 需要运行桌面并完成存储初始化或解锁，CLI 不新建连接、不独立解锁、不处理身份确认。应用锁定或关闭开关后拒绝新操作，已获准请求继续受原超时和生命周期约束。
- 工作区列表反映后端可观测的 SSH 连接，不等于全部前端标签。不支持 RDP 执行、PTY 输入接管或容器/WSL 到宿主机代理。
- 三平台复用原有单程序压缩包结构；Windows GUI 子系统程序在脚本中需使用能等待进程、捕获标准流与退出码的调用方式。具体路径与使用方式见仓库开发说明及程序帮助。

## Agent Skill

- 新增 `termquay` skill，可使用 `npx skills add Sanjeever/termquay --skill termquay -g` 安装，项目级安装去掉 `-g`。
- Skill 使用程序自带帮助、JSON 与精确工作区 ID，安装不包含应用，也不构成远端操作授权。
