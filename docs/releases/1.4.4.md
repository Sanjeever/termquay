## Workspace fixes

- Remove the empty batch-action row above the remote file tree when nothing is selected. Selection actions appear when needed, with keyboard selection and select-all preserved.
- Restore the local terminal renderer alongside the SSH/container renderer when choosing **Restore defaults** in **Terminal and editor**.
- Keep monitoring controls readable in narrow workspaces and preview listener, tunnel and destination roles while editing port forwards.

## Local terminals

- Add local workspace layouts with up to four visible panes, resizing, drag/keyboard pane exchange and maximize/restore. Hidden sessions remain available without restarting their processes.
- Improve focus switching, current-directory inheritance, Chinese IME handling and modified Enter/Ctrl+J input, including Windows terminal key records.
- Add opt-in direct multiline paste, copy-on-selection and explicit bell attention. Preserve the scroll position while browsing earlier output.
- Support native clipboard-image shortcuts for compatible local TUIs and quoted file-path drops without executing the inserted text.
- Update xterm and WebGL rendering, retain inactive renderers within the shared retention policy, support synchronized output and fix device-pixel canvas scaling. Coalesce adjacent PTY output while retaining parsing acknowledgements and independent input.

## Files and configuration editing

- Add **Tools → File transfers**, a persistent dual-pane tab for local/remote and cross-host copies, difference previews and access to background transfers. Paths and selections survive tab and language changes.
- Add explicit **Save and validate** to the remote editor. Reload requires successful validation and separate confirmation; an optional health check follows a successful reload. Ordinary Save does not run commands.
- Reconcile workbench documentation and consolidate shared operational guidance and verification records.

## Verification limits

Checks and platform evidence are recorded in the [verification ledger](https://github.com/Sanjeever/termquay/blob/v1.4.4/docs/development.md#verification-and-known-gaps). The new reset regression uses actual settings components; file-tree layout checks use actual React components with substituted Wails boundaries. Earlier macOS native terminal diagnostics are recorded separately. These checks do not establish Windows/Linux native interaction, real remote workflows or old-to-new desktop upgrades for this release.

## 工作区修复

- 未选中文件时收起远端文件树上方的批量操作栏，消除空白。选中后按需显示，保留键盘选择与全选。
- “终端与编辑器 → 恢复默认”同步重置本地及 SSH/容器终端渲染器。
- 改善窄工作区中的监控控件布局，编辑端口转发时预览监听端、隧道和目标访问端。

## 本地终端

- 新增可保留状态的本地工作区布局，最多展示四个窗格，支持调整比例、拖动或键盘交换、最大化与恢复。隐藏会话继续保留，不重启进程。
- 改善焦点切换、当前目录继承、中文输入法及带修饰键的 Enter/Ctrl+J 输入，包括 Windows 终端按键记录。
- 新增可选的直接多行粘贴、选中后复制及显式响铃提醒。浏览历史输出时保持滚动位置。
- 支持兼容本地 TUI 的原生剪贴板图片快捷键，以及插入经过引用的拖入文件路径，不自动执行插入内容。
- 更新 xterm 与 WebGL 渲染，按共用策略保留后台渲染器，支持同步输出并修复设备像素变化造成的画布缩放。合并相邻 PTY 输出，保留解析确认与独立输入通道。

## 文件与配置编辑

- 新增“工具 → 文件传输”双栏工具标签，支持本地与远端、跨主机复制、差异预览及后台传输。切换标签和语言保留路径与选择。
- 远端编辑器新增显式“保存并验证”。验证通过后仍须单独确认重载，成功后运行可选健康检查；普通保存不执行命令。
- 核对工作台文档，合并共用操作说明与重复验收记录。

## 验证限制

检查与平台覆盖见[验收记录](https://github.com/Sanjeever/termquay/blob/v1.4.4/docs/development.md#verification-and-known-gaps)。新增重置回归使用实际设置组件；文件树布局检查使用实际 React 组件与 Wails 边界替身。此前 macOS 原生终端诊断单独记录。这些检查不能证明本次发布的 Windows/Linux 原生交互、真实远端流程或旧版桌面应用升级已通过。
