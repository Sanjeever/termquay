## 本地终端状态与文件链接

- 在本地终端工作区展示程序上报的执行中、等待、完成和错误状态，并显示程序提供的权限、问题和认证信息。
- 处理终端状态能力探测、嵌套程序标识及提示符、退出清理；避免重复完成通知，区分空闲与任务完成。
- 支持在 VS Code 或 VS Code Insiders 中按行列打开本地终端文件引用，可在外观设置中选择编辑器。
- 按输出对应的目录解析相对文件链接，目录变化后仍可定位先前输出。目录未知时要求选择基准目录，WSL 路径尚未映射时明确报错。
