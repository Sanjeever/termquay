## 终端补全与命令参考

- 新增 POSIX 命令参考，提供中文用途、标准选项与示例，可从终端菜单或命令搜索打开。
- Bash 4.4+ 和 Zsh 可主动启用当前会话的增强补全，支持命令、参数及路径候选。接受候选后等待用户执行，不自动发送回车，普通 Tab 继续交给 Shell。
- 路径补全需确认当前 Shell 与工作区使用同一文件系统，支持 SSH 与本地 Unix 终端；容器、嵌套 SSH 和 Windows 本地终端暂不支持动态路径补全。
- 会话集成不修改 Shell 配置文件，补全通信内容从终端录制日志中过滤。已有快捷键配置保留，新动作避让已使用组合。

## 文件编辑与预览

- 扩展多语言高亮、代码补全与配置片段，语言可自动识别或手动切换，切换时保留正文、光标和撤销记录。
- 新增后台 JSON/YAML 语法诊断，支持多文档 YAML，在行内和问题面板展示错误。
- 新增 Markdown 预览、源码与分栏视图，支持表格、任务列表、代码块高亮、文档锚点及相对链接；外部图片需显式加载，原始 HTML 不执行。
- 新增 PNG、JPEG、GIF 首帧和 WebP 图片预览，支持缩放、重新读取与下载原图；SVG 继续使用源码编辑。
- 文件打开失败时在对应标签提供编码选择、重试或下载入口，完善窄窗口与取消读取反馈。

## 上传与传输

- 上传和拖入文件后先核对连接、目标目录、文件与大小，确认后入队；部分文件未入队时保留原因，可重试剩余文件。
- 任务展示实际传输速度、预计剩余时间与完成阶段，取消请求等待后端结束后更新状态。
- 上传完成后刷新实际目标目录并短暂高亮变更，保留树展开、滚动、选择与编辑草稿；任务提供定位目录入口。
- 修复 Windows 文件拖入被窗口托管方式阻断的问题。

## 备份与恢复

- 重整备份设置，复用已保存的登录信息和备份密码，支持暂停自动备份、立即备份及完整连接检查。
- 按来源设备聚合备份历史，支持设备名称、本机备注，以及在恢复窗口临时输入其他备份密码。
- 支持分项选择连接、命令片段、外观与快捷键恢复；可替换本机连接，或将选中连接导入为独立副本。
- 全量替换前保存加密保护副本，会话存储模式也将副本保留在持久应用目录。未携带凭据的快照在全量替换时仍会替换本机凭据集合，恢复前请核对预览。

## 界面与交互修复

- 统一悬浮说明的停留、关闭和键盘交互，调整窄滚动条与高对比度样式。
- 一次性错误支持在操作附近关闭，重试成功后清除；后台故障保留状态与详情，避免轮询重复提醒。
- 修复 Windows 标题栏交互被原生拖动区域拦截的问题，扩大窗口拖动区域，并让 macOS 双击标题栏遵循系统设置。
