## Workspace toolbar fixes

- Keep the tab action buttons beside the open workspace tabs instead of pushing them to the far side of the title bar. The actions stay accessible when the tab list overflows.
- Give **Open workspaces** and saved working sets distinct icons so they are easier to tell apart.
- Thanks to @MbarkT3STO for reporting the button positioning issue in [#1](https://github.com/Sanjeever/termquay/issues/1).

## Local terminal improvements

- Launch local terminals in a chosen directory, reuse recent directories and open additional tabs from the current directory. Show directory-based tab labels.
- Add a WezTerm shortcut preset and start terminal searches from selected text.
- Confirm before closing active local terminals or quitting with local sessions running.
- Fix native directory detection and clipboard handling on macOS, and restore terminal focus after multiline paste confirmation. Rapid confirmation sends the pasted text once.

## Verification limits

Automated checks and native macOS local-terminal coverage are recorded in the [verification ledger](https://github.com/Sanjeever/termquay/blob/v1.4.3/docs/development.md#verification-and-known-gaps). Toolbar regressions cover macOS, Windows and Linux styles in Chromium; this does not establish native window dragging or WebView behavior on every platform. Windows/Linux native terminal workflows and old-to-new desktop upgrades remain unverified for this release.

## 工作区工具栏修复

- 标签操作按钮紧邻已打开的工作区标签，避免被推到标题栏另一侧。标签列表溢出时，操作按钮仍可访问。
- 为“已打开的工作区”和保存的工作集使用不同图标，方便区分。
- 感谢 @MbarkT3STO 在 [#1](https://github.com/Sanjeever/termquay/issues/1) 反馈按钮位置问题。

## 本地终端改进

- 支持选择本地终端启动目录、复用最近目录，并从当前目录打开新标签。标签按目录显示名称。
- 新增 WezTerm 快捷键预设，支持使用选中文本开始终端搜索。
- 关闭仍在运行的本地终端，或退出仍有本地会话的应用时，增加确认。
- 修复 macOS 原生目录检测和剪贴板处理，多行粘贴确认后恢复终端焦点。快速重复确认时，文本发送一次。

## 验证限制

自动化检查与 macOS 原生本地终端覆盖见[验收记录](https://github.com/Sanjeever/termquay/blob/v1.4.3/docs/development.md#verification-and-known-gaps)。工具栏回归检查覆盖 Chromium 中 macOS、Windows 和 Linux 样式，不能证明所有平台的原生窗口拖动与 WebView 行为。本次发布尚未验证 Windows/Linux 原生终端流程和旧版桌面应用升级。
