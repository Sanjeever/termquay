## Workbench and recovery

- Make active connection filters and selection actions easier to find, keep the workspace switcher visible with many tabs, and distinguish files with the same name by their parent paths.
- Show editor save state and move format controls to the status bar. Offer recovery actions that match the failed read, save or draft download while preserving the draft and error context. Ignore late save failures from a replaced SSH session.
- Group transfers by batch and target, keep active/failed items visible, and separate resume, record removal and staging cleanup. Finished records can be removed offline while retaining staging files; explicit cleanup treats already removed files as cleaned up and preserves records on other failures.
- Improve narrow file navigation, transfer labels and auxiliary-panel controls. Refresh English and Chinese demo screenshots.

## AI execution

- Accept larger bounded tool batches without imposing a fixed cumulative tool-call limit on a turn.
- Reserve part of the runtime budget for a text-only summary and stop repeated identical tool-failure loops. Summary requests disable tools and remain subject to cancellation, lock, disconnect and the hard runtime limit. Command approvals and parsing/output bounds remain in force.

## Verification limits

The [verification ledger](https://github.com/Sanjeever/termquay/blob/v1.4.1/docs/development.md#verification-and-known-gaps) distinguishes automated checks, browser substitutes and historical native/remote checks. Existing records do not establish current three-platform desktop acceptance, real SSH/Docker/RDP/WebDAV or model-provider behavior. Embedded RDP retains its [TLS compatibility boundary](https://github.com/Sanjeever/termquay/blob/v1.4.1/docs/architecture.md#embedded-rdp); native input/IME, clipboard, upgrade/restart and sustained resource behavior need scenario-specific evidence.

## 验证限制

[验收记录](https://github.com/Sanjeever/termquay/blob/v1.4.1/docs/development.md#verification-and-known-gaps) 区分自动检查、浏览器替身及历史原生与远端检查。既有记录不能证明当前三平台桌面、真实 SSH/Docker/RDP/WebDAV 或模型服务均已验收。内嵌 RDP 保留 [TLS 兼容边界](https://github.com/Sanjeever/termquay/blob/v1.4.1/docs/architecture.md#embedded-rdp)，原生输入法、剪贴板、升级重启及持续资源负载仍需专项证据。
