## Linux 服务与日志

- systemd 服务详情支持启动、停止、重启、重新加载及启用或禁用开机启动。操作前核对实际 SSH 目标与服务，使用当前用户权限，不自动提权或重试；超时或取消后需重新核对状态。
- 新增“工具 → 多来源日志”，可将多个 SSH 工作区的文件、systemd 和 Docker 日志并排查看，共用筛选、排除、高亮与 JSON 格式化。
- 日志来源绑定实际 SSH 实例，断线后保留已读内容，重新连接后需重新添加来源。跟随采用有界轮询，不保证连续采集或完整归档。

## CLI 结构化查询

- 新增远端目录与文本、systemd 服务与日志、监听端口及 Docker 容器与日志查询，使用精确 SSH 工作区 ID。
- 支持查询本机保存任务与执行记录，执行结果按页读取，可用修订号核对运行中记录，避免拼接已变化的结果。
- 查询沿用本机 CLI 访问开关、应用锁、当前用户权限与输出边界，不启动任务或启停远端服务；已有 `exec` 权限仍可修改远端。具体命令以所用程序的 `--help` 为准。

## 修复与文档

- 修复 SSH 命令输出复制绕过大小限制的问题，超限时保留截断标记并继续排空输出。
- 核实并精简功能、架构及开发说明，修正巡检记录保存、输出截断判定和服务操作的过时描述，归并历史验证证据与待验场景。
