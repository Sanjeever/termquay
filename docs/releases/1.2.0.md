## 连接与工作区

- 连接支持多标签和保存组合筛选，便于按环境与用途选择主机。
- 新增命名工作集，可保存、追加打开多套 SSH/RDP 布局；恢复后保持断开，连接时重新认证，不重放命令。
- SSH 连接展示分阶段诊断与文件通道检查。无需交互认证的保存连接默认启用本次工作区自动重连，可在会话菜单关闭；重连创建新终端，保留旧输出与文件草稿。
- 延迟探测缩小到相关连接并降低刷新频率，减少后台请求。

## 文件搜索、对比与配置编辑

- 新增远端文件名与文本内容递归搜索，可从结果打开文件并定位。
- 支持任意两份本地或远端文本只读对比，以及跨 SSH 工作区复制文件；成对目录浏览可预览差异并选择复制。
- 支持逐次授权的 sudo 文本编辑，保存时保留文件属性；需要远端已有 sudo 与 GNU coreutils。
- 普通及 sudo 文件默认保存修改前的加密历史，可与草稿比较、载入旧版本，再显式保存；旧历史按边界自动淘汰。
- 可为文件配置独立验证与 reload 命令，执行前核对命令与目标，reload 需确认。
- 日志查看新增筛选、排除、正则高亮、上下文与 JSON 格式化，支持跟随暂停滚动和加密保存复用规则。

## 多主机任务与终端记录

- 支持保存加密多主机任务，配置顺序步骤、参数、超时、并发与分批策略，可在首台完成后人工确认，并按失败策略停止后续调度。
- 任务结果可分组、对比并显式导出 JSON。取消不保证远端派生进程终止，任务不自动回滚或重试。
- 启用当前 Shell 集成后，可查看会话命令索引，按命令、目录和退出码筛选，跳转输出并保存为命令片段。
- SSH 终端支持带时间轴的 asciicast v2 录制与本机离线回放，可暂停、定位、倍速及跳过空闲。录制默认关闭，输出可能包含秘密，录制正文不进入常规备份。

## 诊断与 Docker

- 新增 Linux 进程与 systemd 服务只读诊断，关联监听端口与进程，可从本机或当前 SSH 目标发起 TCP 探测。
- 新增 Docker 容器工作区，通过 SSH 访问已有 Docker Unix socket，查看容器、Compose 分组、日志、挂载、端口及健康与资源指标。
- 支持独立容器终端、端口转发，以及核对目标后启动、停止和重启单个容器；需要当前 SSH 用户已有 socket 权限。

## 本机数据保护与备份

- 持久存储支持主密码保护与启动解锁。遗忘主密码或密钥文件损坏后，无法从密码本身恢复数据。
- 持久存储默认启用本地加密草稿恢复，保留已有关闭选择；恢复草稿须先与最新远端内容对比，再显式保存。
- 加密备份支持工作集、任务、同步预设、连接偏好与日志规则等工作配置的迁移和分项恢复，默认选择工作配置；携带凭据仍需显式勾选。
- 首次配置备份默认勾选保存后启用自动备份，读写与发布检查通过后生效；已有暂停状态保持原样。

## 修复与已知限制

- 修复 macOS 打包时只读许可文件导致签名失败的问题，补齐操作命令核对与记录错误反馈。
- 自动重连尚未完整比较原会话的跳板链配置。同一跳板 ID 被改为另一台已受信任且无需交互认证的主机时，仍可能继续自动重连；修改跳板配置前请关闭相关工作区的自动重连。
- 三平台原生构建与自动测试不替代实际桌面、真实 RDP、SSH/WebDAV 及应用升级链路验收，相关场景仍需在目标环境验证。
