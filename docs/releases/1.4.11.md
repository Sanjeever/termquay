## SSH workspace and remote files

- New SSH workspaces start with the file and monitoring panels collapsed. Panels dock when there is room for the terminal. On narrow windows, the active tool takes over the work area. Select **Back** or press Escape to return to the active tab.
- Open remote files in tabs and return to the most recently used tab in the pane when closing the active tab. Opening **Quick Input** focuses the command draft. Clicking an editor toolbar control keeps focus on that control.
- Use **Show remote files** in command search, or press Command+L on macOS or Ctrl+L elsewhere, to focus the remote directory path. Enter a path, use the folder menu to visit an ancestor, or press Down Arrow to browse the directory and Enter to open the selected item.
- See the source and destination for each file transfer. Expand **Path** to read the full paths.

## Connections and search

- Command search shows active and recent workspaces first when the query is empty. Exact names and prefixes rank higher when you search. Find an open workspace by its saved connection name or open a separate workspace for that connection.
- Narrow connection lists keep **Connect** visible and show address details below the connection name. Connection progress and errors appear on the matching row or workspace. From the row, you can cancel a pending connection, open diagnostics, or retry a failed saved SSH connection.

## SSH 工作区与远端文件

- 新建 SSH 工作区时默认收起文件和监控面板。终端空间充足时，面板可停靠。窗口较窄时，当前工具占用主区。点击「返回」或按 Esc 可回到当前标签。
- 远端文件以标签打开。关闭当前标签时，优先返回同一窗格内最近使用的标签。打开「快速输入」时聚焦命令草稿。点击编辑器工具栏时，焦点留在所点控件上。
- 在命令搜索中选择「显示远端文件」，或在 macOS 按 Command+L、在其他平台按 Ctrl+L，将焦点移到远端目录路径。可输入路径、通过文件夹菜单访问上级目录，或按 ↓ 移到目录列表，再按 Enter 打开所选项目。
- 文件传输任务显示来源和目标。展开「路径」可查看完整路径。

## 连接与搜索

- 命令搜索在没有关键词时优先展示当前和近期工作区。输入关键词后，名称完全匹配和前缀匹配的结果优先。可按保存的连接名称找到已打开的工作区，也可为该连接新开一个工作区。
- 窄版连接列表保持「连接」按钮可见，并将地址详情放在连接名称下方。连接进度和错误显示在对应行或工作区。可在连接行取消连接、查看诊断，或重试失败的已保存 SSH 连接。
