## 内置 AI 工作区助手

- 新增“设置 → AI 助手”，全应用使用一份模型配置，支持 Chat Completions、Messages 和 Responses。API Key 在本机加密保存，提供普通回复及工具调用连接测试。
- 已连接 SSH 工作区可打开右侧 AI 对话面板，支持流式回复、停止、新对话、历史分页与删除，并可与监控切换、调整宽度。
- 内置文件、systemd 服务、端口及容器查询工具。Shell 命令默认逐次展示完整脚本和超时，由用户批准或拒绝；可在设置中关闭确认。
- 工具绑定当前真实 SSH 实例。重连、断线、关闭 AI、应用锁定及退出会取消运行并使旧批准失效；同轮被拒绝或执行状态未知的脚本禁止自动重放。
- 终端选文可通过右键、终端操作菜单或 Shift+F10 加入待发送引用，支持预览和移除，发送前不会请求模型，也不自动读取终端画面或滚动历史。
- 对话正文、标题、摘要、引用和工具结果在本机加密保存。长对话按预算压缩较早上下文，保留本机完整记录；主密码存储下重启可读取历史，恢复历史不会恢复执行或批准。

## 界面与结果展示

- 修正聊天输入区重复焦点边框、选文加入后的输入焦点及错误信息重复呈现。
- 命令结果分别展示标准输出、错误输出、退出码和截断状态，标准输出超限时仍保留错误输出。
- 支持重新连接相同临时目标后查阅原对话，连接目标变化时明确核对原目标与当前目标。

## 使用与验证范围

- AI 默认关闭，与本机 CLI 授权开关独立。问题、主动加入的引用及工具读取的文件和输出会发送到配置的模型服务，可能包含敏感信息。
- 首版 AI 入口限定 SSH 工作区。命令通过独立无 PTY 的 `sh -s` 执行，不继承交互终端的目录、环境或别名，不代填 sudo 密码；取消不能证明远端操作已经撤销。
- AI 配置和历史不进入常规备份，会话存储不保证退出后保留。数据库迁移保留既有连接、分组、凭据和设置。
- 本地验证已覆盖三种协议的流式工具往返、权限与生命周期、加密存储，以及 Windows 原生面板、选文、批准、锁定和历史重启。真实模型、真实 SSH 与其他平台原生交互的验证范围和缺口见开发说明；本机测试服务与 CI 构建不代替真实服务验收。
- macOS 发布与持续集成切换到 GitHub 当前支持的构建环境，继续提供 arm64/amd64 通用压缩包。
