## 界面与交互

- 统一明暗主题、控件、焦点与选中态，精简标题栏、工作区工具栏和设置导航，加入跟随系统偏好的轻量动效。
- 优化连接中心，支持点击列标题排序、固定选择操作区，以及窄窗口下的名称与地址双行布局。
- 连接表单前置名称和分组，提供 SSH / RDP 分段选择与中文必填校验。
- 新增 macOS 原生菜单、系统材质和平台默认快捷键，界面可整体放大至 200%。关闭标签时优先处理当前终端或文件，保留未保存确认。
- 精简传输面板，空任务时保持紧凑，每任务限速移入传输选项。

## 演示模式

- 在“设置 → 外观”开启独立演示工作台，命令搜索输入“演示”或 `demo` 可直接准备连接中心、SSH 工作区和文件编辑三个截图场景。
- 使用固定示例连接、终端输出、目录和监控数据，支持内存文件编辑、标签切换与分栏；演示操作不建立真实连接或写入真实配置、文件和备份。
- 演示中的主题与缩放临时生效，退出后恢复原工作台和外观；演示开关重启后关闭。
- README 截图更新为演示数据。

## 修复与性能

- 修复 macOS 应用包显示 Wails 默认图标的问题。
- 按需载入设置、编辑器和差异视图，合并传输进度与分栏拖动更新。
- 修正目录排序、滚动表头对齐和标签关闭等交互细节。

## 升级说明

- 已有主题和快捷键偏好继续保留；如需使用新的平台默认键位，可在“设置 → 快捷键”复位。
- 首次使用默认跟随系统主题。演示数据用于展示界面，不代表真实 SSH、RDP 或监控采集结果。
