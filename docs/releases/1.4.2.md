## Custom terminal fonts

- Add **Custom** under **Settings → Terminal and editor → Monospace font**. Enter the family name of any locally installed font, including Nerd Fonts for Powerlevel10k and other icon-based prompts. For example, install JetBrainsMono Nerd Font Mono on your computer and enter `JetBrainsMono Nerd Font Mono`.
- Apply font changes to open terminals, editors and the settings preview while preserving sessions, drafts and undo history. Save the preference locally and include it in UI settings backups. Existing font presets and monospace fallbacks remain available.
- Thanks to @MbarkT3STO for the request and screenshot in [#1](https://github.com/Sanjeever/termquay/issues/1).

## Verification limits

Automated and browser checks are recorded in the [verification ledger](https://github.com/Sanjeever/termquay/blob/v1.4.2/docs/development.md#verification-and-known-gaps). Browser rendering does not establish native WebView behavior on every platform. Fonts must be installed on the computer running TermQuay; installing them on an SSH server alone does not make them available locally.

## 自定义终端字体

- 在“设置 → 终端与编辑器 → 等宽字体”新增“自定义”，支持输入本机已安装的字体名称，包括用于 Powerlevel10k 等图标提示符的 Nerd Font。例如，在本机安装 JetBrainsMono Nerd Font Mono，再输入 `JetBrainsMono Nerd Font Mono`。
- 字体切换即时应用于已打开的终端、编辑器和设置预览，保留会话、草稿与撤销记录。偏好保存在本机并随界面设置备份，原有字体预设与等宽后备字体继续可用。
- 感谢 @MbarkT3STO 在 [#1](https://github.com/Sanjeever/termquay/issues/1) 提供建议和截图。

## 验证限制

自动化与浏览器检查见[验收记录](https://github.com/Sanjeever/termquay/blob/v1.4.2/docs/development.md#verification-and-known-gaps)。浏览器渲染不能证明所有平台原生 WebView 行为。字体需要安装在运行 TermQuay 的电脑上，安装在 SSH 服务器上无法供本机使用。
