## SSH 与 AI 工具

- AI 助手按当前 SSH 主机探测结果提供工具，支持 POSIX sh 与 Windows PowerShell 脚本执行，批准界面展示实际解释器。无法识别环境时保留文件工具，不默认按 Linux 执行。
- Windows SSH 增加服务、TCP/UDP 端口和服务控制管理器事件查询。事件结果保留扫描范围，不代表完整应用日志；现有 Docker Unix socket 工具不在 Windows 提供。
- PowerShell 通过标准输入接收 UTF-8 脚本，支持长脚本与中文，不修改远端默认 Shell。CLI 与多主机任务继续使用原有 `sh -s` 契约。

## 文件读取与输出

- AI 文件列表支持名称筛选、分页与续读，文件读取支持按字节范围续读，避免切断多字节字符。目录页为实时读取，文件续读核对属性版本，不构成原子快照。
- AI 文件工具接受 Windows 盘符绝对路径，转换为当前 SFTP 通道使用的路径。
- AI 命令工具支持明确指定 UTF-8、GBK 或 GB18030 输出编码。解码失败保留有界原始字节 Base64 并报告错误；未知状态或解码失败的脚本不自动重放。
- 同步 CLI 帮助与 Agent Skill，明确响应级错误和命令结果字段，补齐原始输出读取说明。
