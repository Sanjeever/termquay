## Remote files and SSH workspaces

- Create files without overwriting existing names, refresh the current directory branch, and delete empty or nonempty directories without following symbolic links.
- Copy files and directories within or between connected SSH workspaces using conflict previews, explicit overwrite choices and bounded scans.
- Open editors above retained terminals, switch between stacked and side-by-side panes, and keep forwarding controls in the resizable auxiliary sidebar.
- Keep transfer tasks inside the file-transfer tool, with manual access from the status bar and continued execution after the tool closes.

## Interface and build corrections

- Separate connection addresses and ports, add host-address copying, and keep protocol headers on one line.
- Add an optional green accent color and middle-click closing for workspace, tool and content tabs.
- Preserve visible editor selections on the active line and Chinese curly quotes in Windows terminal applications.
- Replace macOS build output after compilation succeeds so rebuilding does not truncate a running executable.

## 远端文件与 SSH 工作区

- 新建文件拒绝覆盖已有名称，刷新当前目录分支，删除空目录与非空目录时不递归跟随符号链接。
- 在同一或不同已连接 SSH 工作区间复制文件与目录，提供冲突预览、显式覆盖选择和有界扫描。
- 在保留终端上方打开编辑器，支持上下与左右分栏，将端口转发收进可调整宽度的辅助侧栏。
- 传输任务保留在文件传输工具内，可从状态栏手动查看，关闭工具后继续执行已接收任务。

## 界面与构建修正

- 地址与端口分列，增加主机地址复制，协议表头保持单行。
- 新增可选绿色强调色，支持中键关闭工作区、工具和内容标签。
- 保留活动行上的编辑器选区，以及 Windows 终端程序中的中文弯引号输入。
- macOS 编译成功后再替换产物，避免重新构建时截断运行中的程序。
