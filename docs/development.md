# 开发与使用说明

本文提供从源码运行、日常使用、验证和本地打包入口。设计理由与行为契约见 [架构文档](architecture.md)。以下命令从仓库根目录执行。

## 环境与定义入口

- Go 最低版本与建议工具链由 [go.mod](../go.mod) 的 `go`、`toolchain` 声明决定。允许自动工具链下载的环境会按需选择工具链；使用更高版本时仍需验证兼容性。
- pnpm 版本由 [frontend/package.json](../frontend/package.json) 的 `packageManager` 声明决定，Node 需满足锁定 pnpm/Vite 的要求。使用 [锁文件](../frontend/pnpm-lock.yaml) 安装，不改其他项目或全局工具配置。
- Wails CLI 与 `go.mod` 中 Wails 模块版本保持一致。下方安装命令从模块定义读取版本，不另维护版本常量。
- 原生依赖随目标平台准备：macOS 使用 Command Line Tools；Windows 运行需要 WebView2；Linux 构建需要 C 编译器及 Wails 对应的 GTK/WebKit 开发库。包名随发行版和构建选项核对，不把交叉编译结果当作原生验证。

| 内容 | 定义入口 |
| --- | --- |
| 前端脚本、依赖和 Node 包管理器 | [frontend/package.json](../frontend/package.json) 与锁文件 |
| 开发服务器和端口 | [frontend/vite.config.ts](../frontend/vite.config.ts)、[Taskfile.yml](../Taskfile.yml) |
| 热重载、产品元数据与资源生成 | [build/config.yml](../build/config.yml) |
| 通用绑定与前端构建 | [build/Taskfile.yml](../build/Taskfile.yml) |
| 平台构建、包格式和签名参数 | [macOS](../build/darwin/Taskfile.yml)、[Windows](../build/windows/Taskfile.yml)、[Linux](../build/linux/Taskfile.yml) 的任务定义 |

Taskfile 保留 Wails 模板任务。出现 server、Docker 或 iOS 任务不表示产品支持相应部署形态；当前交付范围是桌面应用。自定义开发端口时，核对 [RDP 服务](../rdp.go) 的精确来源白名单；它不会随 Vite 端口自动变化，不得放开为任意来源。

## 首次运行

仓库已包含生成绑定，先安装依赖并构建前端资源，供桌面根包嵌入：

```sh
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend build
```

将匹配的 Wails CLI 安装到已忽略的 `.tools` 目录，并在当前终端加入 PATH。

Windows PowerShell：

```powershell
$wailsVersion = go list -m -f '{{.Version}}' github.com/wailsapp/wails/v3
$env:GOBIN = Join-Path (Get-Location) '.tools'
go install "github.com/wailsapp/wails/v3/cmd/wails3@$wailsVersion"
$env:PATH = "$env:GOBIN;$env:PATH"
wails3 dev
```

macOS / Linux 的 sh 兼容 Shell：

```sh
wails_version=$(go list -m -f '{{.Version}}' github.com/wailsapp/wails/v3)
GOBIN="$PWD/.tools" go install "github.com/wailsapp/wails/v3/cmd/wails3@$wails_version"
export PATH="$PWD/.tools:$PATH"
wails3 dev
```

开发入口通过项目任务完成绑定生成和前端构建，再启动桌面与前端开发服务器。新终端需要重新将 `.tools` 加入 PATH。浏览器单独打开 Vite 页面无法代替原生 Wails 运行时验证。

## 日常修改与验证

Go 服务签名、模型或事件改变后重新生成绑定，生成目录为 [frontend/bindings](../frontend/bindings)。完整 Wails 构建也会执行该步骤；不要手工修补生成文件来掩盖后端定义问题。

```sh
wails3 generate bindings -ts -i
pnpm --dir frontend check
pnpm --dir frontend build
```

根包通过 `go:embed` 引入 `frontend/dist`，全新检出时先构建前端再编译或测试根包。后端检查可按影响范围选择：

```sh
go test -race ./internal/...
go test -race ./...
```

两条命令分别覆盖内部模块和含桌面服务的全部包，无需每次都运行。`-race` 需要当前平台支持的 race 工具链与 C 编译器；缺失时明确记录未完成竞态检查，普通测试通过不能替代它。纯文档修改检查内容、链接和 diff。

当前自动化主要是 Go 测试；前端 `check` 和 `build` 分别提供类型检查与构建验证，没有前端行为测试脚本。测试名称及实际覆盖以仓库测试为准。带凭据的真实服务测试可能在普通测试命令中执行；缺少配置时会跳过，必须区分通过与跳过。

### 真实 SSH 与 WebDAV

测试配置通过当前进程环境安全注入，不写入仓库或提交真实样例。以下是变量名，不是应用运行所必需的生产配置：

| 测试 | 必要变量 | 范围 |
| --- | --- | --- |
| `TestSG1PTY`、`TestSG1Files`、`TestSG1Monitor` | `SSH_MCP_SERVER_SG1_HOST`、`SSH_MCP_SERVER_SG1_PORT`、`SSH_MCP_SERVER_SG1_USERNAME`、`SSH_MCP_SERVER_SG1_PASSWORD`、`TERMQUAY_TEST_HOST_FINGERPRINT` | SSH 协议栈、隔离 SFTP 文件操作、Linux 采集 |
| `TestRealWebDAV` | `TERMQUAY_WEBDAV_URL`、`TERMQUAY_WEBDAV_USERNAME`、`TERMQUAY_WEBDAV_PASSWORD`、`TERMQUAY_WEBDAV_DIRECTORY` | 真实服务的密文往返、列表、解密和同名拒绝 |

SSH 指纹须来自已核对的测试目标，不能为跑通测试关闭身份校验。文件测试创建并清理本次 `/tmp/termquay-*` 目录；监控运行只读 Linux 采集。WebDAV 目录指定已有可写测试集合，测试在其中创建唯一子目录并清理。遵守 [远端操作边界](../AGENTS.md#凭据与远端操作)，MCP 连通不能替代应用自身链路验证。

监控脚本在 Go 嵌入边界统一为 LF。Windows 工作树曾保留 CRLF，原始字节经 `sh -s` 在真实 Linux 目标复现退出码 2，错误为 `set: Illegal option`；LF 版本成功。脚本执行成功与应用采集链路通过仍需分别验证。

```sh
go test -race -v ./internal/ssh ./internal/files ./internal/monitor -run TestSG1
go test -race -v ./internal/backup -run TestRealWebDAV
```

RDP 自动化使用隔离 TLS 目标验证桥接、TLS 1.2 与身份策略，没有真实 Windows 桌面自动测试入口。真实画面、输入、剪贴板、多会话和各原生 WebView 必须另外验收。当前 TLS 版本边界及原因见 [内嵌 RDP](architecture.md#内嵌-rdp)。

## 使用说明

### 连接与工作区

顶部外层标签保留固定“连接中心”入口，其余标签表示连接工作区；SSH 内层标签表示独立终端或文件。连接中心左侧管理分组，右侧显示连接列表。全局命令搜索和设置保持固定入口。应用内容区不常驻展示品牌，系统标题栏保留原生行为。

外层工作区可拖动排序，或聚焦标签后按 Alt+Shift+左右方向键移动；F2、双击或标签菜单可临时重命名，不修改保存配置。标签菜单提供左右移动，标签栏的“已打开工作区”可搜索定位。连接中心固定在首位，不能移动或关闭；排序与改名保留现有会话实例。

连接菜单的“复制配置”创建独立连接，可选择携带已保存凭据，默认不携带。凭据在后端复制并独立加密，修改或删除原连接不会连带改变副本凭据。

左侧导航提供全部、收藏、最近连接和分组。搜索、协议与名称/地址/最近连接时间排序可组合；搜索包含用户名、端口与分组名称。新建菜单提供连接创建和 OpenSSH 导入，快速连接保持独立入口。收藏可在选中连接后切换，生产/预发布/开发环境在连接表单设置。最近记录在 SSH 认证或 RDP 桌面实际建立后写入，最多保留 50 条，可单独清除。目录显示本应用工作区的连接状态与数量，不探测服务器在线状态。偏好按连接 ID 保存在本机设置，删除或恢复后清理失效引用，不进入 WebDAV 快照。

快速连接默认聚焦地址输入，可先解析 `user@host`、`user@host:port`、`user@[IPv6]:port`、裸 IPv6，以及 `ssh -p <端口> -l <用户名> <主机>`。解析后展开目标与认证供核对，点击连接才发起请求；也可选择手动填写 SSH / RDP。不支持的选项、远端命令、重定向及命令展开会报错，不执行输入文本。普通连接表单优先呈现目标与认证，名称、分组、环境、跳板和远程桌面选项按需展开；私钥文件与粘贴内容按所选来源呈现。

连接中心单击选择时列表行高保持不变，选择操作提供连接、编辑和收藏，删除位于连接菜单；双击或 Enter 优先定位同配置 ID 的已有工作区，右键或菜单按钮可新建另一工作区。方向键移动，F2 编辑，Delete 进入删除确认，Shift+F10 打开菜单。新建、编辑使用独立弹窗。“保存”保存配置与加密凭据；“保存并连接”先保存，连接失败仍保留该配置。配置已保存但偏好写入失败会单独报告。“快速连接”使用临时配置，不自动保存。编辑默认沿用已保存凭据，可选择更换，秘密留空仍保留后端旧值。

SSH 支持密码或私钥内容及可选口令；RDP 使用用户名、密码及可选域。首次 SSH 主机或未通过系统 CA 验证的 RDP 证书在独立身份弹窗核对指纹，已知身份变化阻止连接。连接过程可取消。详细策略见 [身份与本地数据](architecture.md#身份凭据与本地数据)。

SSH 认证可选择 Agent。Unix 默认使用 SSH_AUTH_SOCK，Windows 默认使用 OpenSSH Agent 命名管道，也可填写明确地址；Agent 不可用或没有密钥会报错，不回退密码。私钥可粘贴或通过原生文件选择，文件内容由 Go 读取并按已有凭据规则加密，前端接收短期令牌。新认证字段写入 v2 快照，旧 v1 快照继续可读，未知版本拒绝。

SSH 表单“内网连接”可选择另一已保存 SSH 配置作为单跳跳板，拒绝自引用、循环、多跳和 RDP 跳板；被引用配置不能删除。两端分别核对身份，目标信任按跳板 ID 隔离。取消、失败和关闭释放两端连接，不在跳板启动 Shell，也不开启 Agent 转发。包含跳板引用的快照与布局使用 v3，仍可读取 v1/v2。

连接中心可粘贴或选择 OpenSSH 配置并预览导入，支持具体 Host、通配默认值、HostName、User、Port、IdentityFile、IdentityAgent 和单跳 ProxyJump。Include 限明确选择的文件，含等号与引号路径可展开；未选择项报告后跳过，循环、超限和无效语法拒绝。Match/ProxyCommand 不执行，带 ProxyCommand 的连接不能降级直连导入。冲突可跳过、新增或替换，替换保留配置 ID 并清除旧凭据；配置与本机私钥路径偏好同一事务写入。确认只接受当前预览中的唯一条目，目录变化或预览过期需重新预览。

设置“身份信任”可分页查看 SSH/RDP 记录、撤销或重新探测。合法身份变化需核对旧/新指纹并确认，提交时再次探测；目标再次变化、原记录改变、审核过期或期间撤销会拒绝更新。撤销和更新会清理待确认请求与目标未使用的 RDP 授权，现有会话继续；撤销后下次连接重新核对身份，不能绕过 RDP 证书有效期检查。

应用数据位于 `os.UserConfigDir()` 下的 `TermQuay` 目录，数据库名为 `termquay.db`，路径与密钥库关联规则以 [存储入口](../data.go) 和 [密钥库实现](../internal/store/vault.go) 为准。复制数据库不能替代跨设备备份恢复。密钥库不可用时，界面允许明确选择会话存储；其生命周期与安全边界见架构文档。

切换连接中心、外层标签、面板和设置保留会话，关闭工作区释放资源。SSH 工作区左侧为远端文件，中央为终端/文件标签，右侧为监控；文件与监控开关位于当前 SSH 工具栏。各工作区分别保留目录、滚动、草稿、面板宽度和展开状态，布局偏好作为新工作区默认值。SSH 内层标签切换独立终端与文件；文件列表单击选择、双击或 Enter 打开，方向键移动，F2 重命名，Delete 进入删除确认。路径面包屑可跳转，“编辑目录路径”支持输入完整路径。

SSH 工具栏“重新连接”保留原工作区、旧输出、目录和打开文件，建立新的 SSH 实例与终端，不重放命令。保存配置由后端重新读取凭据，临时连接重新填写认证。旧终端断开后可查找/复制，不能继续输入；可关闭结束标签。重连会核对打开文件的远端版本，变化时保留草稿并阻止直接保存。断线草稿仍受应用退出确认保护。

会话栏显示当前实例的用户名、主机、端口、状态和本机环境标记。编辑保存配置不会改变既有实例的目标显示。SSH 的端口转发与文件、监控位于同一工具栏；连接正常时重新连接收在会话菜单，断开后就地显示。

SSH 工具栏“窗格”可新建右侧终端、移动当前标签、最大化/恢复和合并窗格，最多两个。每个窗格各有标签栏与新建终端入口，分别显示自己的终端和文件；点击或聚焦内容切换当前窗格，动作作用于当前标签。分隔线支持拖动和左右方向键调整比例。内容保持在稳定父容器中，通过网格位置与可见性变化实现移动、最大化与合并，保留实例、输出、撤销记录及草稿。

远端文件面板提供目录前进/后退、按连接保存的书签、当前目录文件名过滤、名称/修改时间/大小排序及隐藏文件开关。目录始终优先显示；过滤不递归搜索。书签最多 32 个，临时连接书签留在本次工作区。目录工具栏和文件菜单可复制完整路径，快速导航会取消旧请求。

传输保留两个并行任务，其余按 FIFO 等待，最多 32 个等待任务与 100 条任务记录。等待可取消，不能直接移除；关闭所属 SSH 实例取消运行及等待。达到限额会报错，需要取消或移除已结束记录后再次操作。

上传支持原生多文件选择和拖入文件面板，单批最多 64 个普通文件，逐文件返回结果。默认跳过同名目标；上传选项可明确选择覆盖，拖入默认跳过。失败、取消或跳过可从任务详情重新传输，填写新文件名另存为，或明确选择覆盖。重试创建新任务，重新打开源和客户端；原 SSH 实例关闭后需从新工作区重新发起。上传/下载在暂存中完成，发布前核对源和目标状态，检测到变化会报错；普通 SFTP 的检查与发布不构成原子比较替换。

文件面板“目录同步”支持本地→远端或远端→本地的手动单向同步。本地目录可输入绝对路径，留空时使用原生目录选择；扫描后显示新增、更新、相同和冲突，选择目录会包含递归项，确认后执行。目标多余文件保留，符号链接与特殊文件冲突需处理后重新预览。扫描可取消，关闭工作区会取消任务；同步失败保留已完成结果，重新预览剩余差异。传输保留普通文件修改时间以便再次比较，不承诺完整元数据保留。

文件、工作区和应用关闭前处理全部草稿，可保存并关闭、放弃或取消；保存失败保留草稿和标签。编辑器默认软换行，折行不改变文件内容。保存期间继续编辑会保留新增修改，关闭需再次处理。冲突后可复制草稿，或确认放弃草稿并重新读取远端内容，编辑器同步实际文档。重新打开连接不会恢复原来的远端 Shell。传输面板收起后任务继续，关闭工作区会取消任务。

保存冲突可打开“对比与合并”，左侧编辑本地草稿，右侧查看最新远端只读内容。采用合并草稿与远端基线后，回到编辑器显式保存；对比期间远端再次变化仍会阻止覆盖。取消对比不改动原草稿，也不会上传内容。

RDP 连接后使用工具栏操作组合键、尺寸、全屏和断开。失败或断开保留工作区，提供“重试”“编辑连接”和可展开技术详情。保存连接重试时重新取得后端凭据与一次性授权；临时连接重新填写密码，不为重试缓存秘密。文本剪贴板默认关闭，按工作区选择，改变后须显式重连生效；开启后通过工具栏手动复制或粘贴，不自动同步。桌面组件初始化失败后，下次显式连接会重新初始化。

RDP 在连接前可选择文本剪贴板和远端分辨率；已连接时修改剪贴板保持当前会话，点击“应用并重新连接”取得新授权后生效。远端分辨率按保存连接留在本机偏好，本地缩放独立选择适合窗口或实际像素。全屏默认收起工具栏，通过顶部“显示工具栏”恢复，也可用键盘聚焦后打开并退出全屏。

RDP 工具栏“应用快捷键”默认本机优先，应用已分配快捷键优先触发命令搜索或设置；选择发送远端后，桌面聚焦时将这些按键交给 RDP 组件。工具栏和其他输入区仍可使用本机入口，选择在当前工作区重连后保留。操作系统截获的按键仍受系统限制，组合键菜单通过桌面组件接口发送。

监控随当前工作区可见性启停，进入设置、切换连接或收起面板会取消采集。首次增量指标显示未知，失败可重试并展开技术详情；过期样本不显示为实时指标。窄窗口将监控放入临时侧面板。底部传输摘要持续更新，上传下载不自动打开详情，点击摘要查看、取消或移除任务，可拖动上边界调整详情高度。

监控的“文件系统”显示挂载点、已用/总量与可用空间，容量独立低频刷新。目标需已有支持 JSON 输出的 util-linux `findmnt`；工具缺失、输出无效或超限会显示容量错误，其他采集继续。容量过期显示未知，可用量保留文件系统保留空间语义。

CPU、内存及网络/磁盘设备速率合计提供最近六分钟趋势，最多保留 120 个采样点。未知、失败与超过十秒的采样间隔断线；切回面板时保留窗口内历史，缺口不补点。网络发送和磁盘写入使用虚线，单设备当前速率保留在详情中。

在线编辑的文件类型、大小、权限与并发覆盖限制见 [远端文件契约](architecture.md#远端文件与监控)。不适合在线保存的文件应下载处理，避免误认为编辑器能够保留全部远端元数据。

设置包含外观与终端、快捷键、命令片段、本地草稿恢复、身份信任、备份恢复和关于；终端字号调整不会重建会话。顶部命令搜索支持查找连接、进入连接中心、切换工作区和操作当前 SSH 面板及终端，方向键选择、Enter 执行、Escape 关闭。默认 `Ctrl/⌘ + Shift + P` 从普通界面、终端、编辑器和 RDP 打开搜索；本机优先时应用快捷键由捕获阶段分发，已分配组合不会同时传给远端。快捷键设置支持录入、冲突提示、清除和复位，按键按本机物理键位保存。未分配按键仍交给输入组件，IME 组合输入与 AltGr 不触发应用动作；系统截获的按键仍受操作系统限制。SSH 专注模式收起左右辅助面板，退出后恢复原状态；窄窗口默认收起辅助面板，文件和监控可分别打开为临时面板。

外观设置支持深色、浅色、跟随系统，界面字体、终端与编辑器等宽字体，以及跟随主题或独立深浅终端配色。本机未安装所选字体时使用后备字体，不下载远程字体。设置保存在本机，可复位；主题与字体切换更新现有终端和编辑器，保留会话、文档和撤销记录，差异视图与查找面板同时适配。原生系统标题栏沿用操作系统外观。

终端右上角提供查找和操作菜单。查找支持 Enter/Shift+Enter 切换匹配、区分大小写和 Escape 返回终端；Ctrl/⌘+Shift+F/C/V 分别查找、复制和粘贴。清空显示不发送远端命令，字号可局部调整与复位。Ctrl/⌘+单击打开 HTTP(S) 链接。含换行（包括末尾换行）的粘贴先预览确认，普通单行直接插入，保留终端 bracketed paste。

设置的“命令片段”支持本机增删改、分组与搜索，正文通过本机主密钥加密。`{{name}}` 表示简单具名文本参数；从命令搜索选中片段后填写并预览，插入选中终端，不额外追加回车。替换不改变 Shell 文本语义，含换行仍需终端粘贴确认；终端或工作区已变化时拒绝插入。片段不会采集输入历史，也不进入 WebDAV 快照。

“本地草稿恢复”默认关闭。启用后，未保存文件正文合并并串行加密写入本机，最多 64 份、单份 2 MiB、总量 8 MiB，保留七天。设置可查看、复制及清除副本；关闭恢复会确认清除。正文不进入 localStorage 或 WebDAV 快照。正常退出会等待待写状态；启用时可“保留本地草稿并退出”，写入失败会显示错误，需明确选择忽略后才能继续。远端文件保存仍独立进行，本机副本不代表上传成功。

上次工作布局在启动时可选择恢复，也可从命令搜索打开恢复入口。布局保存连接目标、标签顺序、临时名称、窗格、目录和文件入口，恢复后保持断开。显式连接会新建终端并重新读取文件；加密草稿先进入最新远端对比，不自动上传或重放命令。保存配置已删除时需重新填写认证，目标改变时阻止直接复用；失效文件保留真实错误，可重新读取或关闭入口。布局不保存凭据、授权、PTY ID、终端输出或正文，不进入 WebDAV 快照。

### WebDAV 快照

在设置的“备份恢复”分类填写 WebDAV 地址、登录信息、相对备份目录和独立备份密码。使用 HTTPS，隔离本地测试允许回环 IP 的 HTTP。目录必须位于服务商已有可写集合下，界面初始值见 [BackupSettings](../frontend/src/features/settings/BackupSettings.tsx)；服务商不允许在根集合创建目录时，改用其授权集合下的相对路径。

“测试连接”检查基址目录读取，不证明指定目录能创建或发布快照。“创建快照”完成后再通过列表确认。需要跨设备带回密码或私钥内容时，显式勾选携带凭据并妥善保管独立备份密码。当前 WebDAV 操作按次填写配置并手动执行。

恢复时先读取快照、输入备份密码并预览，确认后替换连接、分组和凭据。具体替换范围、预览失效条件和本机设置保留规则见 [恢复契约](architecture.md#加密备份与恢复)。

### 构建入口

```sh
wails3 build
wails3 task package
```

本机构建产物进入 `bin/`，Windows 可执行文件带 `.exe`。macOS 默认生成应用包并作本机 ad-hoc 签名；Windows 默认 NSIS 打包需要 `makensis`，MSIX 使用相应 Windows 工具；Linux 包格式及工具按平台 Taskfile 选择。完整构建任务可能执行 `go mod tidy` 并更新绑定，完成后检查实际 diff。

`build/config.yml` 是产品元数据与资源生成入口，平台产物仍由 `build/` 中模板和任务决定。修改 `info` 或文件关联时按该文件说明更新资源，再检查生成 diff；资源生成可能覆盖手工定制，不能用一次重新生成冲掉已有打包改动。

应用图标以 [build/appicon.svg](../build/appicon.svg) 为唯一矢量源稿。使用 SVG 渲染工具导出 `build/appicon.png`（1024px）、Linux 的 `build/linux/icon-128.png` 和 DMG 的 `build/darwin/dmg-file-icon.png`，然后运行 `wails3 task common:generate:icons` 生成 ICO/ICNS。DMG 文件图标沿用同一符号，将生成的 `icons.icns` 同步到 `dmg-file-icon.icns`。Windows 构建由 syso 嵌入 ICO，macOS app 包与 DMG 卷引用 ICNS，Linux 包的 hicolor 路径使用对应 128px PNG。修改资源后需重新构建并启动原生程序检查系统入口，文件生成不能替代任务栏、Dock 或启动器验收。

当前打包入口不代表正式发行就绪。分发前补齐目标系统原生验证、签名分发所需资源和 [依赖许可审计](../THIRD_PARTY_NOTICES.md)，按平台核对声明材料随包携带情况；macOS 应用包已有复制入口，其他平台仍需核对。推送、Release 和签名分发需相应授权。
